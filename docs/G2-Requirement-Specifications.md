# Requirement Specifications

[Home](../README.md)

The G2 mission allocates 25 minutes for setup, execution, and teardown. During the setup period, the team must place the required identification markers, position the robot in the start zone, prepare the operator computer and software stack, load the ping-pong balls, and complete any other pre-run activities. A user guide must also be provided for the teaching staff's reference. Once activated, the autonomous mobile robot must leave the start zone, enter the maze, build a map using LiDAR, and detect the landmarks required for task execution.

The robot must identify two primary stations, Station A (static) and Station B (dynamic), using the markers placed during setup. It must then dock within operational tolerance, align its launcher, and deliver three ping-pong balls to each receptacle. The platform must carry at least nine ping-pong balls, and it may retry a shot if an unloading error occurs. At Station A, the robot must fire into a fixed receptacle of approximately 65 mm radius using a specified timing pattern. At Station B, the target receptacle moves on a motorised linear rail, so the robot must identify the marker, infer the motion timing, and coordinate docking and firing accordingly. After completing delivery, the robot must either continue to the next objective or conclude the mission. Official mission timing stops once the second unloading task is completed.

The bonus mission extends the task to Stations C and D. For this stage, the robot must navigate to the lift lobby using land-based QR markers, detect Station C, issue the required API call to summon the lift, enter the lift safely after arrival is confirmed, and send the appropriate command to travel to Level 2. It must then leave the lift, navigate to Station D, and unload into a fixed receptacle. At the end of the 25-minute window, the team must clear all materials from the arena. Scoring is based not only on payload delivery, but also on completion time and map closure, with additional credit awarded for single-launch ROS 2 deployment and ROS bag recording.
